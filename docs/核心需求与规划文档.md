## 一、项目概述

### 1.1 项目背景

Sales ERP 是一款面向销售团队的轻量级企业资源计划系统，旨在打通销售订单全生命周期管理，实现从客户管理、产品管理、订单创建、审批流转、ERP 同步到回款跟踪的端到端闭环。

系统深度集成**飞书（Feishu/Lark）**审批工作流和**聚水潭（Jushuitan）** ERP 数据同步，帮助销售团队减少跨系统操作，提升业务流转效率。

### 1.2 项目目标

| 目标维度 | 具体目标                                        |
| -------- | ----------------------------------------------- |
| 业务目标 | 实现销售订单线上化、审批自动化、数据同步实时化  |
| 效率目标 | 订单审批周期缩短 50% 以上，减少人工录入错误     |
| 管理目标 | 建立统一客户/产品主数据，支持多维度业务报表分析 |
| 集成目标 | 打通飞书审批和聚水潭 ERP，消除信息孤岛          |

### 1.3 目标用户

- **销售人员**：创建订单、提交审批、跟踪订单状态
- **销售主管/经理**：审批订单、查看团队业绩
- **财务人员**：核对回款、管理预付款
- **采购人员**：创建采购单、跟踪到货入库
- **系统管理员**：用户权限管理、系统配置、操作审计

### 2.2 客户管理

**功能清单：**

- 客户信息 CRUD（名称、联系人、电话、地址、等级）
- 客户等级体系：A/B/C 三级，关联不同价格策略
- 信用额度与账期管理
- **预付款余额**跟踪（支持预付款充值、消费、退款）

**关键字段：**

- `name`：客户名称
- `level`：客户等级（A/B/C）
- `creditLimit`：信用额度
- `paymentTerms`：账期（天）
- `prepaymentBalance`：预付款余额

### 2.3 产品管理

**功能清单：**

- 产品主数据 CRUD（名称、分类、描述）
- SKU 管理（规格型号、编码、价格）
- **价格体系**：基于客户等级的差异化定价
- **聚水潭 SKU 同步**：按品牌（EMIE）自动拉取 SKU 数据
- **物料分类**：树形结构多级分类（成品/半成品/原材料 → 子分类）

**关键字段：**

- `jstGoodsId`：聚水潭商品 ID
- `jstSkuId`：聚水潭 SKU ID
- `skuCode`：内部 SKU 编码
- `salePrice`：销售价
- `costPrice`：成本价

### 2.4 销售订单（核心）

**功能清单：**

- 订单创建（草稿状态）
- 订单编辑（仅草稿/驳回/撤销状态可编辑）
- 订单提交审批（触发飞书审批实例）
- 订单状态跟踪
- 手动推送聚水潭
- **回款登记**（支持现金回款 + 预付款抵扣）
- 订单详情查看（关联审批记录、发货单）
- **数据导出**（Excel 格式）

**订单类型：**

- `sales`：普通销售订单
- `overseas`：海外提货单

**订单状态机：**

```
                    ┌────────────────────────────────────────┐
                    │                                        │
                    ▼                                        │
┌──────┐    ┌──────────────┐    ┌─────────┐    ┌──────────┐ │
│ draft │──▶│pending_approval│──▶│ approved │──▶│synced_jst│ │
└──────┘    └──────────────┘    └─────────┘    └──────────┘ │
    ▲              │                              │          │
    │           rejected                          │          │
    │           reverted                          │          │
    │              │                              ▼          │
    └──────────────┘                         ┌──────────┐    │
                                             │ shipped  │────┘
                                             └──────────┘
                                                  │
                                                  ▼
                                            ┌──────────┐
                                            │completed │
                                            └──────────┘
```

| 状态               | 说明         | 可执行操作       |
| ------------------ | ------------ | ---------------- |
| `draft`            | 草稿         | 编辑、提交审批   |
| `pending_approval` | 待审批       | 等待飞书审批结果 |
| `approved`         | 已审批通过   | 自动推送聚水潭   |
| `synced_jst`       | 已同步聚水潭 | 等待发货         |
| `shipped`          | 已发货       | 登记回款         |
| `completed`        | 已完成       | 全部回款到账     |
| `rejected`         | 已驳回       | 编辑后重新提交   |
| `reverted`         | 已撤销       | 编辑后重新提交   |
| `cancelled`        | 已取消       | 无               |

### 2.5 审批中心

**功能清单：**

- 审批记录列表查询
- 审批详情查看
- 手动通过/驳回审批（备用操作）
- **飞书审批回调处理**（核心）
- **审批状态轮询同步**（高频 10s，兜底机制）
- **状态变更日志**（记录每次状态流转的 from/to）

**审批类型：**

- `sales_order`：销售订单审批
- `collection`：回款审批
- `prepayment`：预付款充值审批
- `purchase_order`：采购单审批

**审批状态映射：**

| 飞书状态               | ERP 状态      | 说明       |
| ---------------------- | ------------- | ---------- |
| `PENDING`              | `pending`     | 审批中     |
| `APPROVED`             | `approved`    | 已通过     |
| `REJECTED`             | `rejected`    | 已驳回     |
| `TRANSFERRED`          | `transferred` | 已转交     |
| `CANCELLED`/`CANCELED` | `cancelled`   | 已取消     |
| `REVERTED`             | `reverted`    | 通过后撤销 |

**审批流程：**

1. 用户在系统提交订单/回款/预付款/采购单
2. 系统调用飞书 Open API 创建审批实例
3. 审批人在飞书收到审批卡片
4. 审批人通过/驳回/撤销后，飞书发送 Webhook 回调
5. 系统接收回调（或轮询检测到状态变化），更新业务状态，触发后续动作

### 2.6 预付款管理

**功能清单：**

- 预付款充值记录创建
- 充值审批（走飞书审批）
- 审批通过后自动增加客户预付款余额
- 预付款消费记录（关联销售订单回款）

### 2.7 采购单管理

**功能清单：**

- 采购单创建（草稿状态）
- 采购单编辑（仅草稿/驳回/撤销状态可编辑）
- 采购单提交审批（走飞书审批）
- **到货入库**（支持部分到货、全部到货）
- 采购单状态跟踪
- **状态变更日志**

**采购单状态机：**

| 状态               | 说明     |
| ------------------ | -------- |
| `draft`            | 草稿     |
| `pending_approval` | 待审批   |
| `approved`         | 已审批   |
| `rejected`         | 已驳回   |
| `reverted`         | 已撤销   |
| `partial_received` | 部分到货 |
| `received`         | 全部到货 |
| `completed`        | 已完成   |
| `cancelled`        | 已取消   |

### 2.8 BOM 管理

**功能清单：**

- BOM（物料清单）创建与版本管理
- BOM 明细项管理（SKU、数量）
- 支持多版本并存，仅激活版本用于采购
- 从 BOM 直接生成分供应商采购单

**关键字段：**

- `productId`：关联产品
- `skuId`：关联 SKU
- `version`：版本号（默认 v1）
- `isActive`：是否激活

### 2.9 供应商管理

**功能清单：**

- 供应商信息 CRUD
- 启用/停用状态管理
- 采购单关联供应商

### 2.10 加工入库

**功能清单：**

- 加工单创建（基于 BOM）
- 加工状态跟踪（待处理/加工中/已完成/已取消）
- 加工完成后入库

### 2.11 物料分类

**功能清单：**

- 树形结构多级分类管理
- 分类编码与名称
- 父分类与子分类层级关系
- 同级排序
- 启用/停用状态

### 2.12 报表分析

**功能清单：**

- 销售汇总报表
- 回款统计报表
- 业务员业绩报表
- **业绩分成**（支持主业务员与协助业务员按比例分成）

### 2.13 操作日志

**功能清单：**

- 全量操作审计日志
- 记录用户、动作、资源、详情、IP、状态
- 管理员可查看和筛选

### 2.14 系统管理

**功能清单：**

- 用户管理（CRUD、启用/禁用）
- **权限配置**：基于角色的细粒度权限控制
- **飞书 User ID 绑定**：用于审批实例创建
- **聚水潭店铺 ID 配置**：用于订单推送

**权限体系：**

| 模块     | 权限点                                           | 说明               |
| -------- | ------------------------------------------------ | ------------------ |
| 销售订单 | `order:view/create/edit/submit/push_jst/collect` | 订单全生命周期权限 |
| 客户管理 | `customer:view/create/edit`                      | 客户主数据权限     |
| 产品管理 | `product:view/create/edit`                       | 产品主数据权限     |
| 预付款   | `prepayment:view/create`                         | 预付款操作权限     |
| 审批中心 | `approval:view/handle`                           | 审批查看/处理权限  |
| 采购单   | `purchase_order:view/create/edit/submit/receive` | 采购单权限         |
| 供应商   | `supplier:view/create/edit`                      | 供应商权限         |

| 加工入库 | `production_order:view/create/edit`              | 加工单权限         |
| 物料分类 | `material_category:view/create/edit/delete`      | 物料分类权限       |

**角色设计：**

- `admin`：管理员，拥有所有权限（`*`）
- `user`：普通用户，按分配的权限点控制

### 4.2 关键实体说明

**SalesOrder（销售订单）**

- 状态字段 `status` 是核心，驱动整个业务流程
- `signerId` 签单人决定订单推送聚水潭时的店铺 ID
- `collectionData` 临时存储待审批的回款数据

**PurchaseOrder（采购单）**

- 关联供应商和采购明细项
- 支持到货入库（partial_received → received）
- 同样走飞书审批流程

**ApprovalRecord（审批记录）**

- 关联销售订单、预付款记录、回款记录或采购单
- `feishuInstanceCode` 飞书审批实例唯一标识
- `type` 区分订单审批/回款审批/预付款审批/采购单审批
- `status` 支持：pending/approved/rejected/transferred/cancelled/reverted

**BomHeader（BOM 物料清单）**

- 按产品 + SKU + 版本唯一标识
- 支持多版本管理，仅激活版本用于业务

**ProductSku（SKU）**

- `jstSkuId` 关联聚水潭 SKU
- `salePrice` / `costPrice` 支持价格管理
- `propertiesValue` 存储规格属性

**MaterialCategory（物料分类）**

- 树形结构，支持多级分类
- `parentId` 指向父分类，`level` 表示层级深度

## 五、核心业务流程

### 5.1 销售订单创建与审批流程

```
┌─────────┐   ┌──────────┐   ┌─────────────┐   ┌─────────────┐
│  创建订单 │──▶│ 草稿状态  │──▶│ 提交飞书审批 │──▶│ pending_approval│
└─────────┘   └──────────┘   └─────────────┘   └─────────────┘
                                                        │
                    ┌───────────────────────────────────┘
                    │
                    ▼
           ┌──────────────┐
           │  飞书审批通过  │────────▶ 自动推送聚水潭 ────▶ synced_jst
           └──────────────┘
                    │
                    ▼
           ┌──────────────┐
           │  飞书审批驳回  │────────▶ 状态变为 rejected ──▶ 可编辑重提
           └──────────────┘
                    │
                    ▼
           ┌──────────────┐
           │  飞书审批撤销  │────────▶ 状态变为 reverted ──▶ 可编辑重提
           └──────────────┘
```

### 5.2 回款流程

```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐

│ synced_jst/ │   │ (含预付款   │   │             │   │             │
│ shipped     │   │  抵扣)      │   │             │   │             │
└─────────────┘   └─────────────┘   └─────────────┘   └─────────────┘
                                                              │
                    ┌─────────────────────────────────────────┘
                    │
                    ▼
           ┌──────────────┐
```

## 八、关键约束与依赖

### 8.1 飞书集成约束

- **审批创建必须使用 `user_id`**（员工编号），不能使用 `open_id` 或 `union_id`
- 用户必须配置 `feishuUserId`，否则无法提交审批
- 飞书审批定义码（`approvalDefCode`）目前为硬编码，后端不做多租户隔离
- 飞书审批通过后撤销（REVERTED）的场景：飞书 API 返回 `status=APPROVED` + `reverted=true`，系统需识别并映射为 `reverted` 状态

### 8.2 聚水潭集成约束

- **签单人必须配置 `jushuitanShopId`**，否则无法推送订单
- 每个签单人可以对应不同店铺，支持多店铺业务场景
- SKU 同步按品牌 `EMIE` 过滤

### 8.3 数据一致性约束

- 订单编辑仅限 `draft`、`rejected`、`reverted` 状态
- 回款金额不能超过剩余应收款（容忍 0.01 元浮点误差）
- 预付款抵扣不能超过客户预付款余额
- 采购单到货数量不能超过采购数量

## 十、风险与应对

| 风险                | 影响           | 应对策略                          |
| ------------------- | -------------- | --------------------------------- |
| 飞书 API 变更       | 审批流程中断   | 封装飞书服务层，集中处理 API 变更 |
| 聚水潭接口不稳定    | 订单推送失败   | Bull 队列重试机制 + 手动重推功能  |
| 数据并发冲突        | 订单状态不一致 | 数据库事务 + 状态机校验           |
| 用户未绑定飞书 ID   | 无法提交审批   | 前端校验 + 管理员提醒             |
| 签单人未配置店铺 ID | 无法推送聚水潭 | 提交时校验 + 明确错误提示         |
| 飞书审批通过后撤销  | 状态未同步     | 高频轮询 + reverted 字段检测      |
