方案总结

  • 技术栈：React 18 + Vite + Ant Design 5 + Axios + React Router
  • 风格：现代轻亮专业版（大白底 + 科技蓝）
  • 布局：左侧固定导航 + 顶部面包屑/用户信息
  • 登录页：左侧品牌渐变背景 + 右侧登录表单
  • MVP 页面：仪表盘、销售订单（列表+新建）、审批中心、报表分析
